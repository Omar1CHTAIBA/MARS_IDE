# MARS - Multi-purpose Advanced Resource Studio

MARS is a lightweight and flexible text editor with file management capabilities and a built-in web preview feature. It is developed using PyQt6 and QsciScintilla, providing a modern UI with syntax highlighting and real-time HTML preview.

## Features
- **File Explorer**: Integrated tree view for easy file navigation.
- **Multi-tab Editing**: Supports multiple open files in a tabbed interface.
- **Syntax Highlighting**: Uses QsciScintilla for enhanced code readability.
- **HTML Preview**: Real-time rendering of HTML files.
- **Keyboard Shortcuts**:
  - `Ctrl+N` - New File
  - `Ctrl+O` - Open File
  - `Ctrl+S` - Save File
  - `Ctrl+Shift+S` - Save As
  - `Ctrl+K` - Open Folder
  - `Ctrl+Shift+B` - Toggle Preview
  - `Ctrl+B` - Toggle File Tree
  - `Shift+F10` - Run Preview

## Dependencies
- `PyQt6`
- `PyQt6.QtWebEngineWidgets`
- `QsciScintilla`

## Project Structure
```plaintext
MARS/
│── MARS.py            # Main application file
│── Lexer.py           # Syntax highlighting setup using QsciScintilla

```
